# Super Spade 1.0 tokens

Product: Super Spade. UI string: `super spade`.

Locked 1.0 pixel source: aurora + glass + hover tray mockup (`super spade • v3`). These values are the source of truth for Rex. Do not use Dead (mango / cream / ink) on Super Spade chrome.

## Compact glass chips

- fill: rgba(255,255,255,0.16)
- border: rgba(255,255,255,0.28–0.30)
- blur: ~12–14px
- height: ~24, pill radius
- weather tint: rgba(125,211,252,0.32)
- keep-awake: warmer glass rgba(251,146,60,0.42) + green live dot; tap-only; NO hover island

Weather hover tray expands. Other chips stay compact. Keep-awake is a tap toggle only.

## Hover island (weather / quota / cpu / calendar)

- fill: rgba(20,16,30,0.72)
- blur: ~28px
- bottom radius: ~22
- soft-join shoulders into the bar — no hard pointer

## Settings

- frosted panel radius ~22
- header `super spade` lowercase ~14 semibold
- row type ~12
- toggles pill ~34×18
- hide-other-icons here; quit secondary/muted

Frosted settings is secondary. No mango cream ink.
